# Chatter Box Node

build a simple web app for nodejs (simple chat app) Node.js with following structure and simple ui
   │
   ├── /
   ├── /health
   └── /api/info

The /api/info endpoint should return:

{
  "application": "NodeOps",
  "version": "1.0.0",
  "hostname": "..."
}
